# Формат climate.json

Этот файл прикладывается к каждому релизу. Дашборд забирает его по постоянной ссылке на последний релиз:

```
https://github.com/mkbdlnv/kz-climate/releases/latest/download/climate.json
```

Это контракт между репозиторием и дашбордом. Если поле добавляется, читатели этого не замечают. Если поле убирается, переименовывается или меняет смысл, нужно увеличить `schema`. Дашборд не примет схему, которую не знает, и продолжит показывать прошлый файл.

## Верхний уровень

| поле | тип | что это |
|---|---|---|
| `schema` | int | версия формата, сейчас `1` |
| `version` | string | тег релиза, например `v2026.10.08-12` |
| `generated_at` | string | когда собран файл, ISO 8601 в UTC |
| `source` | object | набор данных, поставщик, лицензия, как цитировать |
| `code` | object | `repository` и `commit`, из которого собран файл |
| `baseline` | [int, int] | базовый период для аномалий: `[1961, 1990]` |
| `normal` | [int, int] | период климатической нормы для месяцев: `[1991, 2020]` |
| `indices` | object | ключ счётчика дней → подпись с порогом |
| `cities` | array | по объекту на город |

## Город

| поле | тип | что это |
|---|---|---|
| `id`, `name` | string | `almaty`, `Алматы` |
| `lat`, `lon` | number | точка, для которой запрошены данные |
| `data_from`, `data_through` | string | первый и последний день ряда (`YYYY-MM-DD`) |
| `baseline_mean` | number | средняя годовая температура за базовый период, °C |
| `years` | array | по строке на **полный** календарный год, см. ниже |
| `trends` | object | ряд → тренд, см. ниже. Ряды: `mean`, `tmax_mean`, `tmin_mean`, `precip`, `frost_days`, `summer_days`, `hot_days` |
| `warmest` | array | пять самых тёплых лет: `{year, anomaly}`, по убыванию |
| `last_year` | object | `{year, rank, of}`: место последнего полного года среди всех (1 = самый тёплый) |
| `normals` | number[12] | норма средней температуры каждого месяца за `normal`, °C |
| `recent_months` | array | последние 12 полных месяцев: `{month: "2025-10", mean, normal, anomaly}` |

### Год (`years[]`)

| поле | единица | что это |
|---|---|---|
| `year` | | год |
| `mean` | °C | среднее суточных средних |
| `anomaly` | °C | `mean` минус `baseline_mean` |
| `tmax_mean`, `tmin_mean` | °C | среднее суточных максимумов и минимумов |
| `precip` | мм | сумма осадков |
| `frost_days` | дни | Tmin < 0 °C (ETCCDI FD) |
| `ice_days` | дни | Tmax < 0 °C (ETCCDI ID) |
| `summer_days` | дни | Tmax > 25 °C (ETCCDI SU) |
| `hot_days` | дни | Tmax ≥ 30 °C |
| `tropical_nights` | дни | Tmin > 20 °C (ETCCDI TR) |

### Тренд (`trends.*`)

| поле | что это |
|---|---|
| `per_decade` | наклон Сена × 10: изменение за десятилетие в единицах ряда |
| `ci` | 95 % доверительный интервал `per_decade` |
| `change` | наклон × длина ряда в годах: насколько ряд изменился с первого года до последнего |
| `p_value` | двусторонний p-value теста Манна–Кендалла |
| `tau` | тау Кендалла между временем и значением |
| `significant` | `p_value < 0.05` |
| `from`, `to` | первый и последний год ряда |
